I'm a Full Stack Engineer at **[Teramot](https://teramot.com)**, an AI-native data platform where companies connect their data sources, have them processed automatically, and analyze them or build dashboards by talking to an AI agent.

I own features end to end, from UI to API, database and LLM integration. So far I've shipped 850+ commits and ~275 pull requests to a production monorepo built with React, TypeScript, Go, PostgreSQL and AWS.

---

### 🛠️ What I'm working on

- **Conversational AI agent:** chat interface that renders live, interactive components (CRUD cards, forms, previews) from the agent's tool calls over an MCP server, with persisted conversation history and per-turn token usage.
- **AI-generated dashboards:** multi-source dashboards with a template engine, sandboxed widgets, server-side snapshots with exact totals, and paginated results over AWS Athena.
- **Payments and billing:** end-to-end Stripe and Mercado Pago integration (checkout, webhooks, plans, cancellation) plus AWS Marketplace sign-up.
- **Data tooling and onboarding:** table lineage, SQL editor, column metadata, pipeline overview and status notifications, a guided setup wizard, a drag-and-drop file manager, and EN/ES localization.
- **Code quality:** frontend architecture refactors, a design system migration to HeroUI v3, test coverage and CI guards.
